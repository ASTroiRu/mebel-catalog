# Мебель на заказ — этапы A–G

Локальная демонстрационная версия. Next.js App Router, React, TypeScript strict, Tailwind CSS. Сайт не опубликован.

## Запуск

Node.js 22.22.2+ (ветка 22), 24.15.0+ (ветка 24) или 26+ и npm; ограничения связаны с тестовым jsdom. Проверено на Node.js 22.23.4. Точные версии зависимостей — в package-lock.json.

```sh
npm ci
NEXT_TELEMETRY_DISABLED=1 npm run dev -- --port 3017
```

Предпросмотр: http://127.0.0.1:3017. Loopback-сервер не открывается в локальную сеть. Шрифты и изображения хранятся локально.

## Проверки

```sh
NEXT_TELEMETRY_DISABLED=1 npm run typecheck
npm run test:unit
NEXT_TELEMETRY_DISABLED=1 npm run build
NEXT_TELEMETRY_DISABLED=1 npm run start -- --port 3018
```

При работающем production-сервере во втором терминале:

```sh
npm test
```

`npm test` запускает компонентные и HTTP-тесты; `npm run test:unit` — только компонентные, без сервера. Другой адрес задаётся через `TEST_BASE_URL=http://127.0.0.1:3000 npm test`.

В изолированной среде может требоваться разрешение на локальные порты и дочерние процессы. Dev/build используют поддерживаемый `--webpack`, поскольку Turbopack не может открыть внутренний порт в текущей среде. `NEXT_TELEMETRY_DISABLED=1` отключает CLI-телеметрию Next.js; эту настройку можно сохранить через `.env.local` по примеру `.env.example`.

## Что реализовано

A: конфигурация, дизайн-токены, локальный Manrope, фиксированная шапка, мобильное меню, подвал, 404, noindex.

B: главная с тремя слайдами (кухни, шкафы, гардеробные); категории, преимущества, демонстрационная подборка, семь шагов процесса, четыре концепта, условные образцы материалов, FAQ и финальный CTA. Все секции серверные, кроме управления слайдером. FAQ — нативные details/summary.

Слайдер работает только вручную: стрелки, индикаторы, клавиши влево/вправо и горизонтальный свайп. Автопоказа и его переключателя нет. Вертикальные жесты не переключают слайды.

C: каталог, четыре категории, двенадцать изделий. Асинхронный типизированный repository, статические маршруты, хлебные крошки, демонстрационные характеристики и цены. Галерея с миниатюрами, увеличением и клавиатурной навигацией. Три связанных изделия из других категорий задаются в данных.

Каталог: http://127.0.0.1:3017/catalog/
Пример изделия: http://127.0.0.1:3017/catalog/kuhni/linia/

D: единая форма расчёта и замера. Категория и модель подставляются из страницы или карточки. Проверяются обязательные поля, телефон +7 или 8, положительные размеры и JPG/PNG/PDF до 10 МБ. После проверки появляется сообщение «Форма проверена. Это демонстрация — заявка не отправлена». Закрытие очищает поля и выбранный файл. Форма не отправляет и не сохраняет данные.

E: галерея и четыре концепта, бесплатный замер, процесс работы, материалы, о компании, FAQ, контакты и проект политики конфиденциальности. Страницы статически генерируются из типизированного repository. Концепты используют референсные изображения и условные палитры; материалы — CSS-образцы, не фотографии. Неизвестные контакты отмечены «Демо».

Концепты: http://127.0.0.1:3017/projects/
Замер: http://127.0.0.1:3017/zamer/

F: уникальные метаданные, canonical/Open Graph для 30 страниц, WebPage/WebSite и BreadcrumbList, безопасные robots/sitemap. Изображения поддерживают AVIF/WebP; вторичный текст затемнён для контраста на тонированных поверхностях. SITE_URL задаёт origin при сборке, не включает индексацию. Настройка предпросмотра и ограничения публичного режима: docs/seo-and-preview.md.

G: отредактированы тексты, описания сверены с реальными изображениями. На главной подобраны соответствующие им модели; все 12 схем перерисованы под заявленные конструкции. Добавлено замыкание Tab/Shift+Tab в форме и галерее. Проверены 30 страниц на ширинах 360/768/1440 в Firefox. Отчёт: docs/stage-g-report.md; скриншоты: docs/qa/stage-g.

## Границы демоверсии

- Каталог и изделия доступны. Демонстрационная форма, концепты и информационные страницы доступны. Всего 30 содержательных URL.
- Цены есть только на страницах изделий и в похожих изделиях, явно условные. Цен на главной и в категориях нет. Изображения и модели не представлены как выполненные работы или реальные изделия компании.
- Источники и лицензии: public/images/home/CREDITS.md. Фото шкафа и гардеробной, 3D-иллюстрация кухни — Unsplash License. Схема шкафа-купе и условные CSS-образцы созданы для проекта.
- Нет отправки данных, аналитики, CRM, базы данных или внешнего хранения. Название и контакты — демо.
- Meta robots и HTTP X-Robots-Tag содержат noindex. Демонстрационная sitemap пуста; robots.txt запрещает обход. Публичная индексация требует отдельной команды и проверки контента.
- Noindex не является контролем доступа. Для будущего удалённого preview нужна защита на уровне платформы/сервера.

## Структура

- src/app — маршруты, metadata и глобальные стили.
- src/components/layout — общий каркас; src/components/home — главная и слайдер.
- src/content/local/home.ts — типизированные данные главной, src/content/navigation.ts — маршруты и доступность ссылок.
- public/fonts и public/images/home — локальные ресурсы и лицензии.
- tests — компонентные и HTTP-проверки.
- docs/specification.md — исходное ТЗ; docs/stage-a-report.md, docs/stage-b-report.md docs/stage-c-report.md и docs/stage-d-report.md и docs/stage-e-report.md и docs/stage-f-report.md — отчёты.

Content repository и каталог реализованы. Форма, страницы и техническая SEO-архитектура реализованы; доступные проверки общей приёмки выполнены. Каждый этап начинается после отдельного разрешения.


Данные каталога: src/content/models.ts, src/content/repository.ts и src/content/local/catalog.ts. При подключении CMS заменяется адаптер repository. UI не импортирует local/catalog.ts. Concept и InformationPage реализованы; данные находятся в src/content/local/pages.ts и доступны через repository.

Схемы моделей в public/images/products созданы для проекта. Это условные изображения без размеров, не рабочие чертежи. Референсные фотографии повторяются у моделей одной категории и явно обозначены как иллюстрации направления.

### Повторная браузерная проверка

Используется установленный Firefox, отдельный временный профиль и WebDriver BiDi. Запустите production-сервер на 3018 и браузер в отдельном терминале:

```sh
mkdir -p /tmp/mebel-firefox-profile
firefox --headless --no-remote --profile /tmp/mebel-firefox-profile --remote-debugging-port 9222 about:blank
node --import tsx scripts/browser-qa.mjs
```

Скрипт создаёт отдельную сессию в тестовом браузере и завершает её после проверки. Не направляйте его на браузер с личным профилем. Скриншоты и результаты по умолчанию сохраняются в /tmp/mebel-browser-qa; путь задаётся QA_OUTPUT_DIR. TEST_BASE_URL позволяет изменить локальный адрес проверяемого сайта. Ширина окна не эмулирует реальную мобильную ОС или экранную клавиатуру.
