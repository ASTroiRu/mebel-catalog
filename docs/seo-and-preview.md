# SEO, предпросмотр и будущий публичный режим

## Текущее состояние

`siteConfig.demo` в `src/lib/config.ts` равен `true`. Все HTML-страницы получают meta robots и HTTP X-Robots-Tag с noindex; robots.txt запрещает обход, sitemap.xml содержит пустой urlset и не перечисляет демоадреса. Robots.txt не защищает от доступа и сам по себе не гарантирует удаления URL из индекса. При запрете обхода бот может не прочитать noindex; для удалённого демо нужна настоящая защита доступа.

Canonical и Open Graph строятся из SITE_URL, заданного на момент сборки. По умолчанию это http://127.0.0.1:3017 — адрес локального предпросмотра. Переменная принимает только HTTP(S) origin без пути, параметров, фрагмента и учётных данных. Установка другого SITE_URL не включает индексацию. После смены origin нужна новая сборка.

JSON-LD описывает страницы, сайт и хлебные крошки. Демомодели не размечаются как продаваемые товары: нет Offer, рейтингов, наличия или вымышленных реквизитов. Строки экранируются перед вставкой в script. Open Graph использует локальный интерьерный референс с честной подписью.

## Ограничение доступа к удалённому preview

Сейчас dev/start слушают только 127.0.0.1. Сайт не опубликован. Для будущего закрытого preview можно использовать аутентификацию платформы либо TLS reverse proxy с Basic Auth, который закрывает весь origin, включая ресурсы, robots и sitemap. Пример для существующего TLS server-блока nginx:

```nginx
# Example only: not deployed by this stage.
location / {
    auth_basic "Private preview";
    auth_basic_user_file /etc/nginx/mebel-preview.htpasswd;
    proxy_pass http://127.0.0.1:3017;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Accept $http_accept;
}
```

Файл паролей создаётся администратором вне репозитория. Не открывайте upstream-порт наружу; используйте HTTPS для передачи учётных данных. Проверка перед публикацией preview: без авторизации HTML и ресурсы должны возвращать 401; после авторизации — страницы с noindex. Этот пример не применён и не проверен на реальном сервере: хостинг и домен пока не выбраны.

## Публичный режим — только отдельным изменением

В окружении нет переменной, снимающей noindex. После отдельного разрешения нужно подтвердить реальные данные компании, изображения и права, цены, юридические документы, условия и обработку заявок; согласовать политику и согласие. Затем задать реальный HTTPS SITE_URL и изменить `siteConfig.demo` на false отдельным проверяемым изменением кода. Генераторы metadata, robots, sitemap и HTTP-заголовков используют это значение совместно. Публичная ветка отказывает для HTTP и точных имён localhost, 127.0.0.1 и ::1. Это не полная проверка публичности адреса: перед запуском нужно дополнить её проверкой всего loopback-диапазона и нормализованных имён (например, localhost с завершающей точкой). Это техническая проверка, не автоматическое подтверждение готовности бизнеса.

Публичная sitemap строится из repository и включает 30 содержательных страниц, без 404. Даты lastModified не выдумываются. До фактического перехода нужно убрать демотексты (включая имя WebSite в JSON-LD) и заменить референсы; текущая реализация публичной ветки не означает разрешения запуска.

## Производительность и доступность

Страницы статически генерируются. Локальный variable Manrope подключён через next/font с display:swap; внешних запросов шрифта нет. Next Image отдаёт AVIF или WebP по Accept, использует адаптивные размеры и кэш минимум 4 часа. При изменении картинки по прежнему имени учитывайте этот кэш; для немедленного обновления меняйте имя. Первый hero/основной кадр предзагружается; остальные карточки загружаются лениво. Рекомендация для reverse proxy — сохранять Accept.

Серверные секции, нативные details/summary, ограниченные клиентские компоненты и единственная форма сохраняются; тяжёлые библиотеки не добавлены. Будущий интерфейс событий описан в src/lib/analytics.ts, реализация ничего не делает и не принимает персональные данные.

Проверяются заголовки, подписи изображений, структура JSON-LD, клавиатурные сценарии компонентов и noindex. JSDOM не заменяет браузер. LCP ≤2,5 с, INP ≤200 мс и CLS ≤0,1 остаются целями: нужны браузерные измерения на мобильной сети и полевые данные после разрешённого запуска. Полная WCAG-проверка и screen reader также требуют отдельной ручной проверки.
