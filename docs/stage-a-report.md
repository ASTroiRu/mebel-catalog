## Функциональность

Next.js 16.4.6 / React 19.3.1 / Tailwind 4.3.5, strict TypeScript. Статические главная-заглушка и 404. Серверный layout, клиентский disclosure-компонент мобильного меню. Палитра ТЗ, Manrope локально, ширина контента до 1280 px, фиксированная светлая шапка с резервом места в основном содержимом. Единый подвал с регионом, демо-контактами и недоступными пока юридическими ссылками. Skip-link, видимый фокус, reduced motion.

Меню закрывается кнопкой, Escape с возвратом фокуса, при выходе фокуса, клике вне и переходе к desktop. Это немодальная навигация: блокировка фокуса и прокрутки не используется. Будущие разделы помечены aria-disabled и не являются действующими ссылками. Расчёт disabled с видимым пояснением. Контакты и факты компании не выдуманы.

Noindex: meta robots и X-Robots-Tag, включая 404. Нет формы, серверных обработчиков, базы данных, внешней аналитики, sitemap или публикации.

## Ошибки среды и решения

- Песочница блокирует npm-сеть, локальные порты и некоторые дочерние процессы. После разрешённого расширенного запуска установка, Webpack-сборка, сервер и HTTP-тесты прошли.
- Turbopack дважды завершился ошибкой внутреннего bind; выбран поддерживаемый Webpack для dev/build. Первая Webpack-сборка внутри песочницы не смогла прочитать результат дочернего TypeScript --showConfig; расширенный запуск прошёл.
- Порт 3000 занят: для проверки использованы 3017 (dev) и 3018 (production), чужие процессы не остановлены.
- Рабочий Git-репозиторий отсутствует; служебный read-only .git не изменялся, коммиты не создавались.

## Ограничения и следующий этап

Проверки не являются полным аудитом WCAG, тестом со screen reader или замером Core Web Vitals. Увеличение текста и другие браузеры отдельно не проверялись. Никаких результатов по ним не заявляется.

Вместо полноценной главной — явно обозначенный временный экран. Каталог, концепты, информационные страницы и форма пока недоступны. У всех будущих пунктов уже указаны целевые URL в данных навигации. Фотографии, цены и галереи не добавлены. Sitemap, canonical, Open Graph, CMS-слой и аналитический интерфейс относятся к следующим этапам.
