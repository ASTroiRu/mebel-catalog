# Этап D — единая демонстрационная форма

Реализован 11 ноября 2026 года после разрешения пользователя. Этап E не начат.

## Поведение

Кнопки расчёта и замера открывают общую форму. Категория и модель определяются по текущей странице или выбранной карточке, включая похожие изделия. Мобильное меню закрывается при открытии формы; после закрытия фокус возвращается к переключателю меню.

Обязательны тип мебели, имя, телефон в формате +7 и согласие. Размеры необязательны, допускается заполнить часть; введённые значения должны быть положительными числами. Комментарий необязателен. Можно выбрать JPG/JPEG, PNG или PDF размером до 10 МиБ. Неподходящий файл блокирует успешную проверку до удаления или замены.

Ошибки показываются после взаимодействия с полем или попытки проверки. Первая ошибка получает фокус. После успешной проверки появляется точное сообщение:

> Форма проверена. Это демонстрация — заявка не отправлена

Отправки, чтения содержимого файла, сохранения контактов и аналитики нет. Закрытие размонтирует форму и очищает поля и ссылку на File. Страница политики относится к E; вместо неработающей ссылки показано пояснение о подготовке проекта политики.

Нативный dialog закрывается кнопкой и Escape, восстанавливает фокус и прокрутку. На мобильных экранах предусмотрена нижняя панель с внутренней прокруткой и учётом visualViewport; поля имеют размер шрифта 16px.

## Основные файлы

- src/components/forms/quote-form.tsx — интерфейс, поля, ошибки, жизненный цикл диалога.
- src/components/forms/quote-provider.tsx — общая точка открытия, контекст, уведомление.
- src/lib/quote-validation.ts, src/lib/quote-context.ts — чистая валидация и выбор контекста.
- src/components/ui/quote-button.tsx — активные кнопки расчёта и замера.
- src/app/layout.tsx, src/app/globals.css — подключение формы, viewport и стили.
- Главная, категории, изделия, карточки, мобильное меню и подвал — подключение кнопок и актуальные подписи.
- tests/quote-validation.test.tsx, tests/quote-form.test.tsx, tests/smoke.test.mjs — проверки этапа.

## Проверки

- Production-сборка npm run build успешна, включая TypeScript и статическую генерацию.
- npm run test:unit: 18 из 18.
- npm test против production-сервера: 26 из 26. Проверены 17 URL каталога, главная, 404, ссылки, noindex, контекст кнопок и отсутствие формы в исходном серверном HTML.
- Компонентные тесты проверяют ошибки, границы файлов, очистку, возврат фокуса, сообщение успеха; перехватчики запрещают сетевую отправку, чтение файлов и запись в хранилище.
- Независимое ревью не выявило блокирующих замечаний. Исправлено повторное создание live-region сообщений ошибок; добавлена регрессионная проверка стабильности DOM-узла.
- Локальный предпросмотр http://127.0.0.1:3017 отвечает HTTP 200 с noindex.

## Ограничения проверки

Браузерное управление в текущем окружении недоступно. JSDOM не проверяет реальную отрисовку, нативное удержание фокуса, экранную клавиатуру и прокрутку мобильного браузера. Эти проверки остаются для визуальной приёмки. Сайт не опубликован, индексация отключена.
