# Этап F — SEO и оптимизация

Завершён 11 ноября 2026 года после разрешения пользователя. Этап G не начат. Сайт не опубликован, индексация не включалась.

## Реализовано

Единый генератор metadata задаёт уникальные Title/Description, абсолютный canonical и Open Graph для всех 30 содержательных страниц. Origin берётся из SITE_URL при сборке, по умолчанию http://127.0.0.1:3017. Адрес проверяется на HTTP(S), отсутствие учётных данных, пути и параметров. Неизвестный публичный домен не выдумывался.

Добавлены JSON-LD WebSite, WebPage/CollectionPage/AboutPage/ContactPage и BreadcrumbList. Разметка соответствует содержимому; вымышленных Offer, рейтингов, отзывов, наличия и реквизитов нет. Строки экранируются от закрытия script. У 404 отдельные метаданные и настоящий HTTP-статус.

robots.txt и sitemap.xml генерируются штатными средствами Next. В деморежиме sitemap не содержит URL, robots запрещает обход и не рекламирует sitemap. Meta robots и X-Robots-Tag сохраняют noindex. Единственное значение demo управляет политикой; переменная окружения не может включить индексацию. Публичная ветка sitemap подготовлена на основе repository, без выдуманных дат обновления.

Next Image настроен на AVIF/WebP по Accept и кэш минимум 4 часа. Сохранены адаптивные размеры, приоритет первого изображения и ленивая загрузка карточек. Страницы остаются статическими; локальный variable-шрифт с display:swap сохранён без добавления зависимостей. Нативные FAQ и существующие компоненты не заменялись тяжёлыми библиотеками.

На странице галереи заголовки карточек исправлены на H2. Вторичный текст на тонированной поверхности имел расчётный контраст 4,13:1; цвет слегка затемнён, теперь 4,59:1. Добавлен регрессионный тест для обычного текста на обоих основных фонах. Будущий интерфейс аналитики принимает только имена событий, текущая реализация ничего не отправляет, не хранит и не логирует.

## Основные файлы

- src/lib/seo.ts, content-paths.ts — metadata, origin, политика индексации, сериализация и список 30 маршрутов.
- src/components/seo/structured-data.tsx, src/components/catalog/breadcrumbs.tsx — JSON-LD и хлебные крошки.
- src/app/robots.ts, sitemap.ts — служебные маршруты.
- Все шаблоны src/app/**/page.tsx, layout.tsx и not-found.tsx — подключение SEO.
- next.config.ts — форматы изображений, кэш и согласованная политика HTTP-заголовков.
- src/components/home/home-card.tsx, src/app/globals.css — заголовки и контраст.
- src/lib/analytics.ts — неактивный интерфейс будущих событий.
- tests/seo.test.tsx, seo-http.test.mjs, accessibility.test.tsx — новые проверки.
- .env.example, README.md, docs/seo-and-preview.md — конфигурация и инструкция по закрытому предпросмотру.

## Проверки

- Финальная npm run build успешна, включая TypeScript, 30 содержательных страниц и служебные маршруты.
- npm run test:unit: 25/25.
- Финальная npm test против production-сборки: 38/38.
- HTTP-обход обнаружил ровно 30 страниц через внутренние ссылки; проверены canonical, Open Graph, уникальность title/description, один H1, JSON-LD и конечные адреса хлебных крошек.
- Проверены пустая sitemap, robots без ссылки на неё, noindex и настоящие 404.
- Endpoint оптимизации реально вернул image/avif и image/webp для соответствующих Accept с заголовками кэширования.
- Unit-тест подтверждает round-trip вредоносной строки в JSON-LD без неэкранированного символа <.
- Тест контраста сначала воспроизвёл недостаточный контраст, после изменения прошёл. Остальные тесты формы, слайдера, галереи, данных и ссылок проходят.
- Предпросмотр http://127.0.0.1:3017 отвечает HTTP 200 и оставлен работающим. Отдельный тестовый сервер остановлен.

## Ревью и ограничения

Независимое ревью не нашло блокирующих дефектов текущего деморежима. До будущего публичного запуска отложены два небольших замечания: проверка origin пока исключает только точные localhost/127.0.0.1/::1, а не весь loopback-диапазон и варианты записи; имя WebSite в JSON-LD пока содержит «Демо». Оба пункта явно включены в инструкцию запуска. Включение публичного режима сейчас не разрешено.

Инструкция docs/seo-and-preview.md содержит пример TLS reverse proxy с аутентификацией и loopback-upstream. Пример не развёрнут: хостинг и домен не выбраны. Robots/noindex не выдаются за контроль доступа. При запрете обхода бот может не прочитать noindex — для удалённого демо требуется реальная защита доступа.

Браузерного управления нет. Lighthouse, реальные LCP/INP/CLS, screen reader, мобильная клавиатура и визуальная проверка не выполнялись. Цели Core Web Vitals не объявляются достигнутыми; арифметическая проверка палитры не означает полной WCAG-сертификации. Фотографии материалов, реальные контакты и согласованный юридический документ по-прежнему требуют исходных данных.
