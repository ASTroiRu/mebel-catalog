# 1. Общая информация о проекте

**Тип проекта:** многостраничный сайт-каталог с генерацией заявок.

**Тематика:** изготовление корпусной мебели на заказ.

**География:** Москва и Московская область.

**Целевая аудитория:** клиенты среднего плюс и премиального сегментов.

**Основные категории:**
1. Кухни.
2. Шкафы.
3. Шкафы-купе.
4. Гардеробные.

**Бизнес-модель:**
- Мебель изготавливается по индивидуальным размерам.
- Производство осуществляется партнёрским производством.
- Предусмотрены бесплатный предварительный замер и расчёт.
- Сайт не является интернет-магазином.
- Нет корзины, онлайн-оплаты и оформления заказа.
- Основная конверсия — запрос расчёта стоимости.
- Дополнительная конверсия — запись на бесплатный замер.

Название компании, логотип, контакты и юридические данные пока неизвестны. Используй явно обозначенные заглушки.

Не выдумывай факты о компании, отзывы, реальные проекты, гарантии, сроки изготовления или производственные мощности.

# 13. SEO

Подготовь полноценную техническую SEO-архитектуру.

Для каждой страницы:

- Уникальный Title.
- Уникальный Description.
- Один H1.
- Корректная структура H2/H3.
- Человекопонятный URL.
- Canonical.
- Open Graph.
- Alt-тексты изображений.
- Внутренняя перелинковка.

Реализуй:

- XML Sitemap.
- Robots.txt.
- BreadcrumbList.
- Подходящую структурированную разметку.
- Корректную обработку 404.

## Два режима индексации

**Демонстрационный режим:**

- Все страницы должны иметь `noindex`.
- Не публикуй демонстрационные URL в открытой sitemap.
- Предусмотри возможность ограничения доступа к предпросмотру.
- Не считай robots.txt достаточным способом скрыть сайт от индексации.

**Публичный режим:**

Включение индексации допускается только после отдельной настройки и проверки реального контента, контактов, юридических документов и обработки заявок.

По умолчанию используй демонстрационный режим.

Оптимизируй:

- Изображения.
- Шрифты.
- Размер JavaScript.
- Слайдер.
- Галереи.
- CSS.
- Кэширование.
- Статическую генерацию.

Используй адаптивные изображения, подходящие форматы AVIF/WebP и отложенную загрузку вне первого экрана.
