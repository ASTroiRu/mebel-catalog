# Корректировки после этапа F

По запросу пользователя автопоказ главной карусели полностью удалён вместе с переключателем и связанными таймерами/обработчиками. Сохранены стрелки, индикаторы, клавиши влево/вправо и горизонтальные свайпы. Одновременно отображается только активное изображение.

Форма принимает 11 цифр с префиксом 8 или +7, в том числе пробелы, скобки и дефисы. Подсказка и сообщение ошибки обновлены. Неполные, слишком длинные номера и строки с буквами по-прежнему отклоняются. Отправки данных нет.

Это явные изменения исходных требований к автопоказу и телефону; этап G не начат. README и тесты приведены в соответствие новому поведению. Компонентные проверки: 20/20.

Production-сборка и проверка TypeScript успешны.
