# Stage D Implementation Plan

> Execute inline using executing-plans. Stage D explicitly authorized. No E–G routes/publication.

**Goal:** One local-only quote/measurement form across all current pages.
**Architecture:** Client provider in server layout, native dialog mounted only while open. Thin CTA buttons; typed pure validation functions. Categories/products supplied as small context lists by repository. No network/storage/Server Actions.
**Tech Stack:** Existing Next/React/TS/Tailwind and JSDOM/node:test. No new dependencies.
**Spec:** ../../specification.md

## Constraints
- Required category, name, +7 phone, consent; optional positive partial dimensions, comment, JPG/PNG/PDF <=10 MiB.
- No empty untouched errors; live validation after interaction; submit validates all and focuses first invalid field.
- File remains only a local File reference, never read/uploaded/persisted. Closing unmounts form and clears all data/file.
- Exact success notice: «Форма проверена. Это демонстрация — заявка не отправлена».
- Desktop 480–560 px modal; mobile bottom sheet/internal scroll, native focus trap, Escape/close, no backdrop dismissal, restore focus/scroll.
- Demo/noindex remain. Privacy page not created before E; consent UI explicitly says policy draft is not yet available, no fake legal link.

## Review Focus
- Header CTA on product page infers category/model; explicit card context overrides current route.
- Focus restoration when mobile-menu CTA disappears: return to menu trigger.
- Invalid file must block validation until replaced/removed; closing clears it.
- Interaction never sends a request, stores PII, or logs contents.
- Visual viewport resize/keyboard and Escape do not leave page locked.
