- Без цен, вымышленных отзывов/проектов/сроков/гарантий. Только помеченные демо-данные и лицензированные иллюстрации.
- Форма остаётся недоступной до D, страницы категорий/изделий до C, концептов до E. Никакой публикации/индексации/аналитики.

## Review Focus
- Автовращение останавливается при focus/hover/ручном управлении; возобновление только явно пользователем.
- Reduced motion и скрытая вкладка не запускают автоматические переходы.
- Инициальный HTML содержит только первое приоритетное изображение слайдера; остальные монтируются при выборе.
- Неизменный размер области фото, один H1; captions не накладываются на фото.
- Все карточки честно обозначены демонстрационными, не имитируют доступные маршруты.
