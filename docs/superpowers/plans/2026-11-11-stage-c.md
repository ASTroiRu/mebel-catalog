# Stage C Implementation Plan

> Execute inline with executing-plans. Stage C explicitly authorized; no D–G implementation.

**Goal:** Каталог, 4 категории, 12 изделий и доступные галереи.
**Architecture:** Async typed repository over local data; server route templates with generateStaticParams; client gallery with native modal dialog. UI imports repository/models only for catalog data.
**Tech Stack:** Existing Next.js / strict TS / Tailwind / React. No new dependencies.
**Spec:** ../../specification.md

## Constraints
- Exactly 17 new routes: catalog + 4 categories + 12 products. Unknown and wrong-category products return 404.
- No prices on home/catalog/categories. Demo prices only product detail and 3 explicitly related mixed-category products.
- Each product has stable ID/slug, SEO fields, individual dimensions, body/facade materials and demo marking.
- No forms, integrations, publication or indexing. Keep user's dev server running for preview.

## Review Focus
- Wrong category + valid product must not resolve.
- Related IDs valid, distinct, exclude current model, span 3 other categories.
- Modal Escape/close restores focus and body scroll; keyboard arrows wrap.
- Gallery 75/25 desktop, horizontal mobile thumbs; captions identify illustrations, not real projects.
- Existing home links and mobile menu work after enabling catalog routes.
